# Carvia - The resume that gets you hired
AI-powered resume tailoring and cover letter generation. Paste any job description and get an ATS-ready resume in seconds.


Live: https://carvia.work

## What it does
- Resume Tailor — Upload resume (PDF/DOCX/TXT), paste job description, Claude AI rewrites it
- Cover Letter — Generate personalized cover letter matched to the role
- Dashboard — All tailored resumes saved and accessible anytime
- 5 Templates — Classic, Modern, Minimal, Professional, Executive
- PDF Download — Download tailored resume as formatted PDF

## Tech Stack
- Frontend: React + Vite + Tailwind CSS → Netlify
- Backend: Python + FastAPI → Render.com
- AI: Anthropic Claude API
- Auth + DB: Supabase (email + Google OAuth)
- Domain: carvia.work
